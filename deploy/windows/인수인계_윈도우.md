# 인수인계: Windows 노트북에서 문제노트 돌리기

이 노트북에서 일하는 세션은 이 문서를 먼저 읽고 순서대로 진행해 주세요. 자세한 명령은 같은 폴더의 `윈도우_배포_안내.md`에 있어요.

## 목표
- GitHub `main`(SQLite 판, 맥 운영 서버와 같은 코드)을 받아 이 노트북에서 맥 운영 서버와 **똑같이** 돌린다.
- Cloudflare Tunnel 임시 주소로 바깥에서 접속되게 한다 (맥과 같은 방식). 고정 주소는 사용자가 원할 때만.
- 재부팅 후에도 자동으로 켜지고, 매일 DB를 백업한다.
- DB는 SQLite 유지 (2026-11-12 결정). MySQL은 `mysql-version` 브랜치에만 있고, 사람이 많아지면 옮긴다. 지금은 MySQL 작업을 하지 않는다.

## 순서
1. **Node·Git 확인**: `node -v`가 v24.x(최소 22.13), `git --version`. 없으면 `winget install OpenJS.NodeJS.LTS`, `winget install Git.Git`.
2. **코드 받기**: OneDrive 밖(예: `C:\문제노트`)에 `git clone https://github.com/Rlaslrbs/captima_LMS.git 문제노트`. `npm install`은 필요 없다(외부 패키지 없음).
3. **cloudflared.exe**: Windows용을 받아 `tools\bin\cloudflared.exe`로 둔다.
4. **데이터 (사용자에게 확인)**: 맥 `data\`의 `app.db`(+ 서버를 안 끄고 복사했으면 `app.db-wal`, `app.db-shm`), `admin_path.txt`, `gemini_key.txt`를 USB로 받아 `data\`에 넣었는지 묻는다.
   - 받았으면 그대로 쓴다. `data\`에 이미 파일이 있으면 덮어쓰기 전에 사용자에게 확인한다.
   - 데이터 없이 시작하기로 했으면: 한 번 켰다 끈 뒤 `npm run import` → `npm run hide` (공개 상태를 맥과 같게).
5. **켜기**: `powershell -ExecutionPolicy Bypass -File .\deploy\windows\start-all.ps1`. 임시 주소가 뜨는지, `http://127.0.0.1:4000/`이 열리는지 본다.
6. **자동 시작·백업**: 관리자 권한 PowerShell에서 `register-tasks.ps1`. 작업 스케줄러에 `문제노트-시작`, `문제노트-백업`이 보이는지 본다.
7. **노트북 설정 안내**: 절전 끄기, 덮개 닫아도 켜짐, 활성 시간, 자동 로그온은 사용자가 직접 한다. 방법만 안내한다.

## 맥 운영 서버와 같은 점 (바꾸지 말 것)
- 서버 실행: `node server/server.js` (추가 환경 변수 없음). HOST는 `127.0.0.1`, 바깥 접속은 Tunnel로만.
- Gemini 키: `data\gemini_key.txt` 첫 줄.
- 관리자 화면: 이 노트북 안에서만 (`ADMIN_REMOTE`, `ADMIN_PASSWORD`는 설정하지 않음).
- 숨김 문제: MIS 59, IE216 54 (공개하지 않기로 함).

## 하지 말 것
- 테스트 스위트나 검증 스크립트를 임의로 돌리지 않는다. 사용자가 요청할 때만.
- `data\app.db`, 키, 관리자 비밀 주소를 git·채팅·문서에 쓰거나 남에게 주지 않는다. 학생 기록을 바꾸지 않는다.
- 사용자 확인 없이 `data\` 덮어쓰기, 프로세스 강제 종료, 작업 스케줄러 삭제를 하지 않는다.
- `main`에 바로 push하지 않는다. 고칠 것이 생기면 브랜치 + PR.

## 끝나면 사용자에게 보고할 것
- `127.0.0.1:4000`이 열리는지, 바깥 주소(주소만, 관리자 비밀 주소는 제외)
- 맥 데이터를 옮겼는지, 새로 시작했는지
- 자동 시작·백업 등록 여부, 사용자가 직접 해야 할 것
- PowerShell 스크립트에서 오류가 났다면 `data\logs\` 로그 내용 요약
