# Windows 노트북으로 문제노트 운영하기

GitHub에서 코드를 받아 **Windows 노트북 한 대**에서 서버와 DB(SQLite)를 돌리고, Cloudflare Tunnel로 인터넷에 여는 순서예요.
맥 운영 서버(`node server/server.js` + 임시 주소 Tunnel)와 **같은 방식**으로 돌아가게 맞춰 두었어요. 맥의 `tools/start_beta.sh`에 해당하는 것이 `start-all.ps1`이에요.

> **코드는 GitHub, 데이터는 USB.** GitHub에는 코드와 문제 세트만 있어요. 학생 기록(DB), 관리자 비밀 주소, Gemini 키는 GitHub에 없으니 맥에서 직접 옮겨야 해요.

---

## 0. 준비물

- Windows 10/11 노트북 (유선 인터넷 권장)
- 맥에서 옮겨 올 파일 4개 (3장)
- (고정 주소를 원하면) 내 도메인 1개와 무료 Cloudflare 계정

---

## 1. Node.js와 Git 설치

PowerShell을 열고:

```powershell
winget install OpenJS.NodeJS.LTS
winget install Git.Git
```

설치 후 PowerShell을 **새로 열고** 확인:

```powershell
node -v
git --version
```

`node -v`가 `v24.x`(최소 22.13)면 됩니다. 외부 패키지가 없어서 `npm install`은 필요 없어요.

---

## 2. GitHub에서 코드 받기

OneDrive가 동기화하지 않는 곳(예: `C:\`)에 받으세요. 바탕화면·문서 폴더는 OneDrive가 `app.db`를 잡아 오류를 낼 수 있어요.

```powershell
cd C:\
git clone https://github.com/Rlaslrbs/captima_LMS.git 문제노트
cd C:\문제노트
```

그다음 Windows용 `cloudflared-windows-amd64.exe`를 Cloudflare 공식 페이지에서 받아 이름을 `cloudflared.exe`로 바꾸고 `C:\문제노트\tools\bin\cloudflared.exe`에 두세요. (`tools\bin`은 git에 올라가지 않는 폴더예요.)

---

## 3. 맥에서 데이터 옮기기 (맥 운영 서버와 똑같이 하려면 필수)

1. **맥에서 서버를 끕니다.** 서버가 켜져 있으면 최신 기록이 `app.db-wal`에만 있을 수 있어요.
2. 맥 `문제노트_플랫폼/data/`에서 아래 파일을 USB로 복사해 Windows `C:\문제노트\data\`에 넣어요.

| 파일 | 내용 | 없으면 |
|---|---|---|
| `app.db` | 문제 · 공개 상태 · 학생 기록 전부 | 빈 DB로 시작 (5장) |
| `app.db-wal`, `app.db-shm` | 서버를 끄지 않고 복사했을 때만 같이 | — |
| `admin_path.txt` | 관리자 비밀 주소 | 새 비밀 주소가 만들어져요 |
| `gemini_key.txt` | Gemini 키 (AI 채점·진단) | AI 기능이 꺼져요 |

> 이 파일들은 학생 기록과 비밀 값이에요. **git·채팅·공유 드라이브에 올리지 마세요.** `.gitignore`가 `data/`를 막고 있어요.

---

## 4. 켜기

```powershell
cd C:\문제노트
powershell -ExecutionPolicy Bypass -File .\deploy\windows\start-all.ps1
```

- 창에 `https://○○.trycloudflare.com` 주소가 뜨면 그 주소로 접속돼요. 맥과 같이 **켤 때마다 주소가 바뀌어요.**
- 이 노트북에서 `http://127.0.0.1:4000/`이 열리면 서버는 정상이에요.
- 관리자 화면은 **이 노트북에서만** 열려요: `http://127.0.0.1:4000/` + `data\admin_path.txt`의 비밀 주소. Tunnel(바깥)로 들어오면 관리자 화면은 없는 것처럼 보여요.
- 끄려면 그 창에서 `Ctrl+C`.

---

## 5. (데이터 없이 새로 시작할 때만) 문제 넣기

맥의 `app.db`를 옮기지 않았다면, 한 번 켰다 끈 뒤 GitHub에 있는 문제 세트를 넣어요.

```powershell
npm run import
npm run hide
```

- `import`: `data\import\*.json` 문제 세트를 전부 넣어요. 팩에 `publish: false`인 문제(IE216 등)는 숨김으로 들어가요.
- `hide`: `data\import\<과목>_hidden.txt` 목록(MIS 59문제 등)을 다시 숨겨요. 이렇게 하면 공개 상태가 맥 운영 서버와 같아져요.
- 학생 기록은 새로 시작해요. 기록까지 같게 하려면 3장처럼 `app.db`를 옮기세요.

---

## 6. 고정 주소로 바꾸기 (선택, 도메인 필요)

1. Cloudflare에 도메인을 올린 뒤 PowerShell에서 한 번만:

```powershell
tools\bin\cloudflared.exe tunnel login
tools\bin\cloudflared.exe tunnel create munje-note
tools\bin\cloudflared.exe tunnel route dns munje-note munje.내도메인.com
```

2. `deploy\windows\config.yml.example`을 `%USERPROFILE%\.cloudflared\config.yml`로 복사하고 `<tunnel-id>`, 도메인을 채워요.
3. `start-all.ps1` 위쪽의 `$TunnelName = ""`를 `$TunnelName = "munje-note"`로 바꿔요.

---

## 7. 자동 시작 · 자동 백업

PowerShell을 **관리자 권한**으로 열고 한 번만:

```powershell
cd C:\문제노트
powershell -ExecutionPolicy Bypass -File .\deploy\windows\register-tasks.ps1
```

- **문제노트-시작**: 로그온할 때 서버와 Tunnel이 켜져요. (임시 주소면 주소가 바뀌니 `data\logs\tunnel.err.log`에서 새 주소를 확인하세요.)
- **문제노트-백업**: 매일 03:00 `data\backups\nightly\`에 DB 사본, 최근 30개 보관. 직접 돌리려면 `npm run backup`.
- 외장 드라이브에도 두려면 등록 전에: `[Environment]::SetEnvironmentVariable("BACKUP_DEST", "E:\문제노트백업", "User")`

## 9. 코드 업데이트 받기

```powershell
cd C:\문제노트
git pull
```

그다음 `start-all.ps1` 창을 껐다 다시 켜요. `data\`는 git이 건드리지 않아서 기록은 그대로예요.

## 10. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `cloudflared.exe 가 없어요` | 2장 위치(`tools\bin\cloudflared.exe`)를 확인 |
| `4000 포트에 이미 서버가…` | 다른 창의 서버를 끄거나 작업 관리자에서 `node` 종료 |
| 주소가 안 나옴 | `data\logs\tunnel.err.log` 확인, 인터넷 연결 확인 |
| 서버가 바로 꺼짐 | `data\logs\server.err.log` 확인 (Node 버전, `data\` 폴더 권한) |
| 스크립트 실행이 막힘 | `-ExecutionPolicy Bypass`를 붙여 실행 (위 명령 그대로) |
| 한글이 깨져 보임 | 파일을 다른 편집기로 저장하지 말고 git에서 받은 그대로 쓰기 |
