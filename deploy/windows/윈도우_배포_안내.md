# Windows 노트북으로 문제노트 배포하기

이 문서는 **Windows 노트북 한 대**에서 서버와 DB를 돌리고, Cloudflare Tunnel로 인터넷에 여는 순서예요.
맥에서 쓰던 `tools/start_beta.sh`의 Windows 버전이 `start-all.ps1`이에요.

---

## 0. 준비물

- Windows 10/11 노트북 (유선 인터넷 권장)
- 문제노트 폴더 전체 (이 저장소의 `문제노트_플랫폼` 폴더)
- (고정 주소를 원하면) 내가 가진 도메인 1개와 무료 Cloudflare 계정

---

## 1. Node.js 설치 (Node 24 LTS)

PowerShell을 열고:

```powershell
winget install OpenJS.NodeJS.LTS
```

설치 후 PowerShell을 **새로 열고** 확인:

```powershell
node -v
```

`v24.x`가 보이면 됩니다. (`node:sqlite`를 쓰므로 22.13 이상이어야 해요.)

---

## 2. cloudflared.exe 받기

Cloudflare 공식 페이지에서 Windows용 `cloudflared-windows-amd64.exe`를 받아서
이름을 `cloudflared.exe`로 바꾸고 아래 위치에 두세요.

```
문제노트_플랫폼\tools\bin\cloudflared.exe
```

> 맥의 `tools/bin/cloudflared`는 맥 전용이라 Windows에서는 쓸 수 없어요.

---

## 3. 데이터 옮기기 (맥 → Windows)

맥에서 쓰던 기록을 그대로 가져오려면 아래 파일을 Windows의 같은 위치에 복사하세요.

- `data\app.db` (문제 · 학생 기록 전부)
- `data\admin_path.txt` (관리자 비밀 주소)

> 학생 기록이 들어 있는 파일이라 **저장소(git)에 올리지 마세요.** USB나 개인 클라우드처럼 본인만 보는 곳으로 옮기세요.

처음 시작하면서 `data\` 폴더가 없으면 서버가 자동으로 만듭니다.

> **주의:** `문제노트_플랫폼` 폴더를 OneDrive나 다른 동기화 폴더(바탕화면·문서 포함) 안에 두지 마세요. 동기화 프로그램이 `app.db`를 잡고 있으면 서버가 오류를 내거나 기록이 깨질 수 있어요. `C:\문제노트_플랫폼`처럼 동기화되지 않는 곳에 두세요.

---

## 4. 서버 먼저 확인하기 (인터넷 연결 전)

```powershell
cd 문제노트_플랫폼
node server\server.js
```

브라우저에서 `http://127.0.0.1:4000/` 이 열리면 성공이에요. 확인 후 `Ctrl+C`로 끄세요.

---

## 5-A. 임시 주소로 바로 열기 (도메인 없이, 가장 빨리)

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\windows\start-all.ps1
```

- `$TunnelName`을 빈 값으로 두면 됩니다. (`start-all.ps1` 상단의 `$TunnelName = "munje-note"`를 `""`로 고쳐 주세요.)
- 창에 `https://○○.trycloudflare.com` 주소가 뜨면 그 주소를 테스터에게 보내면 돼요.
- 주소는 켤 때마다 바뀌어요.

---

## 5-B. 고정 주소로 열기 (도메인 필요)

1. Cloudflare에 도메인을 등록하고 Zero Trust 메뉴에서 로그인합니다.
2. PowerShell에서 한 번만:

```powershell
tools\bin\cloudflared.exe tunnel login
tools\bin\cloudflared.exe tunnel create munje-note
```

3. 출력된 `<tunnel-id>`를 메모하고, `deploy\windows\config.yml.example`을
   `%USERPROFILE%\.cloudflared\config.yml`로 복사해서 값을 채웁니다.
4. DNS 연결 (한 번만):

```powershell
tools\bin\cloudflared.exe tunnel route dns munje-note munje.내도메인.com
```

5. 이제 `start-all.ps1`을 실행하면 `https://munje.내도메인.com`으로 접속돼요.

---

## 6. 자동 시작과 자동 백업 등록

PowerShell을 **관리자 권한**으로 열고 한 번만:

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\windows\register-tasks.ps1
```

- **문제노트-시작**: 노트북에 로그온할 때 서버와 터널이 자동으로 켜져요.
- **문제노트-백업**: 매일 새벽 3시에 `data\backups\nightly\`에 DB 사본을 남기고, 최근 30개만 보관해요.

지금 바로 확인하려면:

```powershell
Start-ScheduledTask -TaskName 문제노트-시작
```

---

## 7. 노트북 설정 (꼭 확인)

- **절전:** 설정 → 시스템 → 전원에서 "절전 모드: 사용 안 함"으로 바꿔 주세요. `start-all.ps1`도 실행 중에는 잠들지 않게 막아 줘요.
- **덮개 닫을 때:** 제어판 → 전원 옵션 → "덮개를 닫을 때 동작"을 **아무 동작 안 함**으로 바꿔 주세요.
- **업데이트 재부팅:** 설정 → Windows 업데이트 → "활성 시간"을 수업 시간으로 설정하면 낮에 재부팅되지 않아요.
- **자동 로그온:** 노트북을 켜면 자동으로 로그인되도록 하면 재부팅 후에도 사이트가 살아나요. (`netplwiz`에서 설정)

---

## 8. 백업을 다른 곳에도 두기

외장 USB나 다른 드라이브에 한 부 더 두려면 `register-tasks.ps1`을 실행하기 전에 환경 변수를 설정하세요.

```powershell
[Environment]::SetEnvironmentVariable("BACKUP_DEST", "E:\문제노트백업", "User")
```

백업을 직접 한 번 돌려 보려면:

```powershell
node deploy\windows\backup.mjs
```

## 9. 자주 생기는 문제

| 증상 | 원인 · 해결 |
|---|---|
| `cloudflared.exe 가 없어요` | 2단계 위치에 파일이 없어요. 이름과 위치를 다시 확인하세요. |
| `4000 포트에 이미 서버가...` | 다른 서버가 켜져 있어요. 그 창을 닫거나 작업 관리자에서 `node`를 끝내세요. |
| 주소가 안 나옴 | `data\logs\tunnel.err.log`를 확인하세요. 인터넷 연결이 끊겨 있을 수 있어요. |
| 재부팅 후 사이트가 안 열림 | 자동 로그온 설정, 작업 스케줄러의 `문제노트-시작` 상태를 확인하세요. |
| 관리자 화면이 안 열림 | 관리자 화면은 **이 노트북 안에서만** 열려요. `http://127.0.0.1:4000/` + `data\admin_path.txt`의 비밀 주소로 들어가세요. |

로그는 `data\logs\`에 있어요 (`server.log`, `server.err.log`, `tunnel.log`).

## 10. DB는 SQLite로 두고, 사람이 많아지면 MySQL로 옮기기

- **지금(2026-11-12 결정):** SQLite(`data\app.db`)를 씁니다. 별도 DB 서버가 필요 없고, 이 규모(동시 30명 안팎)에서는 충분해요.
- **MySQL로 옮길 때 (사용자가 많아졌을 때):**
  1. MySQL 서버를 이 노트북에 설치하고 `.env`에 접속 정보를 넣습니다.
  2. `node --env-file=.env tools/mysql-setup.mjs all --content-only`로 표와 문제를 옮깁니다. 학습 기록까지 옮기려면 `--with-learners`를 붙입니다.
  3. `backup.mjs`를 `mysqldump` 방식으로 바꾸고, `start-all.ps1`의 서버 실행 줄을 `node --env-file-if-exists=.env server/server.js`로 바꿉니다.
- 옮기기 전에는 SQLite 백업(`data\backups\nightly\`)을 꼭 보관하세요.
