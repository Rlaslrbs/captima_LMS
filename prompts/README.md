# prompts/ — 역할별 프롬프트 모음

Claude에게 역할을 줄 때 **새 대화 첫 메시지**에 아래 한 줄을 붙여넣어요. 저장소 루트의 `CLAUDE.md`(공통 규칙)는 항상 먼저 읽혀요.

| 역할 | 파일 | 첫 메시지 |
|---|---|---|
| 서버 | `서버_프롬프트.md` | `prompts/서버_프롬프트.md 를 읽고, 서버 담당으로 일해 줘. 이번에 할 일: …` |
| DB | `DB_프롬프트.md` | `prompts/DB_프롬프트.md 를 읽고, DB 담당으로 일해 줘. 이번에 할 일: …` |
| 프론트엔드 | `프론트엔드_프롬프트.md` | `prompts/프론트엔드_프롬프트.md 를 읽고, 프론트엔드 담당으로 일해 줘. 이번에 할 일: …` |
| 학습 리포트 엔진 | `학습리포트_엔진_프롬프트.md` | `prompts/학습리포트_엔진_프롬프트.md 를 읽고, 학습 리포트 엔진 담당으로 일해 줘. 이번에 할 일: …` |
| 진단 태깅 | `진단태깅_프롬프트.md` | `prompts/진단태깅_프롬프트.md 를 읽고, 진단 태깅 담당으로 일해 줘. 과목: …, 단계: …` |
| 변형 문제 작성 | `변형문제_작성_프롬프트.md` (팀원용: `…_팀원용.md`) | 파일 안의 "새 채팅 첫 메시지" 참고 |
| 새 과목 문제 세트 | `../과목추가_프롬프트.md` | 파일 안 안내 참고 |

## 같은 환경에서 일하려면
- Claude Code는 이 저장소 폴더에서 열어요 (그래야 `CLAUDE.md`가 읽혀요).
- 모델은 **Sonnet, 노력 높음**이 기본이에요. 독립 판정(`third`)처럼 다른 모델이 필요한 단계만 바꿔요.
- 한 번에 한 역할만 맡겨요. 두 역할이 같은 파일을 고치면 서로 덮어써요. 파일 담당은 `CLAUDE.md` 4장 표를 따라요.
- 이 폴더의 프롬프트를 고치면 PR로 올려서 모두 같은 내용을 쓰게 해요.
