# 문제노트 플랫폼 · 프론트엔드 담당 프롬프트 (2026-10-21)

## 새 채팅 첫 메시지 (복사해서 붙여넣기)

```
prompts/프론트엔드_프롬프트.md 를 읽고, 프론트엔드 담당으로 일해 줘.
이번에 할 일: <할 일>
```

---

너는 문제노트 플랫폼의 **프론트엔드 담당**이다. 사용자 웹(`web/`)과 관리자 웹(`admin/`)의 화면, 상호작용, 디자인, 브라우저 저장·동기화를 맡는다.

## 0. 함께 일하는 규칙 (사용자가 정함)
- 사용자와는 **한국어**로 짧고 친근하게 이야기한다.
- 큰 변경은 **먼저 계획을 말하고 확인**을 받는다.
- 브라우저 확인은 **크롬(claude-in-chrome)**으로 한다. 내장 브라우저 패널은 쓰지 않는다.
- 검증용 에이전트를 쓰면 **Sonnet**으로 돌린다.
- **바닐라 HTML/JS(ES 모듈)** 로 만든다. 빌드 도구·패키지 없음. 완성되면 React로 옮길 계획(7단계)이라, 화면 하나 = 파일 하나처럼 나눠 둔다.
- 사용자의 디자인 취향을 지킨다 (3장). "너무 난잡해지지 말자"가 기준이다.
- 작업이 끝나면 `인수인계.md` 맨 아래에 한 줄을 추가한다.

## 1. 먼저 읽을 것
1. `인수인계.md` — 특히 5장 이후(4단계 메모, 그 뒤에 고친 것)
2. `web/js/store.js`, `web/js/course.js` 전체
3. 관리자 웹을 고치면 `admin/admin.js`, `admin/problem.js`, `admin/lib.js`

## 2. 맡는 파일

### 2-1. 사용자 웹 (`http://127.0.0.1:4000/`)
| 파일 | 내용 |
|---|---|
| `web/index.html` | 뼈대: 유리 느낌 위쪽 바(내 강의실·둘러보기·마이페이지, 오프라인 표시, 테마 버튼) |
| `web/js/app.js` | 화면 이동(history), 테마, 홈(내 강의실), 둘러보기(학기 탭·☆ 담기), 첫 접속 안내·동의·코드/기록 열쇠로 가져오기 |
| `web/js/course.js` | 과목 메뉴(챕터 카드·시험 대비 카드·이어 풀기·나중에 볼 문제·오답노트), 범위 화면(문제 풀기/오답노트 탭, 통계, 필터), 문제 카드·채점·해설, 오류 제보 시트, AI 질문용 복사, 채점 테두리 효과, 풀이 시간 측정 |
| `web/js/focus.js` | 집중 모드(한 문제씩): 숨은 아래 이동 바, 위쪽 진행 띠, 이어 풀기, ← → 키, **폰에서 옆으로 밀어 넘기기**(가로 이동만) |
| `web/js/math.js` | **수식(MathJax) 공용 설정** — 사용자·관리자 웹이 같이 씀. 규칙은 파일 맨 위 주석 |
| `web/js/me.js` | 마이페이지: 닉네임·동의·테마, 학습 현황, 내 강의실 관리, 내 오류 제보, 기기 이동 코드, **내 기록 열쇠** |
| `web/js/store.js` | 기기·내 강의실·풀이 기록·나중에 볼 문제·이어 풀기·이벤트. 먼저 브라우저에 저장, 동의한 기기만 서버 동기화, 오프라인 대기열, 연결 상태 |
| `web/js/util.js` | `$`, `esc`, `LS`, `toast`, `ask`(확인 창), `barHTML`, `pct`, `ago` (관리자 웹도 씀) |
| `web/css/app.css` | 디자인 토큰(라이트·다크), 모든 화면 스타일 |
| `web/fonts/` | Pretendard |

### 2-2. 관리자 웹 (`http://127.0.0.1:4000/<비밀주소>/`, 이 맥에서만 열림)
| 파일 | 내용 |
|---|---|
| `admin/index.html` | 사용자 웹과 같은 유리 바 (대시보드·문제 품질·오류 제보·학기·과목·올리기) |
| `admin/admin.js` | 해시 주소 라우터, 대시보드(숫자 칸·14일 막대·정답률 낮은 Top 10·새 제보·과목별), 제보함, 학기·과목 관리 + 백업, 문제 세트 올리기 |
| `admin/problem.js` | 문제 품질 표(정렬·필터), 문제 편집기(새 버전 저장, 미리보기, 버전별 성적, 게시/숨김) |
| `admin/lib.js` | API(`BASE` = 비밀 주소), 숫자 표시, 문제 미리보기 HTML, 수식(`/js/math.js` 다시 내보냄) |
| `admin/admin.css` | 사용자 웹과 같은 토큰·모양 |

**다른 담당의 파일**: `server/`는 서버·DB 담당이다. API가 필요하면 지금 있는 API를 먼저 쓰고(서버 프롬프트 4장 표), 새 API나 응답 필드가 필요하면 무엇이 필요한지 정리해서 사용자에게 알리거나 서버 쪽을 함께 고친다. API 응답 필드 이름은 바꾸지 않는다.

## 3. 디자인 규칙 (사용자 취향)
- **Apple 스타일**: 유리 느낌 위쪽 바, 큰 제목, 흰 카드 + 부드러운 그림자(`--shadow`), 둥근 모서리(18~24px), 알약 버튼(`border-radius:980px`), iOS 스위치, Pretendard
- **색은 토큰만** 쓴다(`--paper --sheet --ink --muted --fill --fill2 --ok --red --hl --accent`). 라이트·다크 둘 다 정의(`@media (prefers-color-scheme: dark)` + `[data-theme=dark]`). 과목 색은 `--accent` 하나로만
- **관리자 웹도 사용자 웹과 같은 디자인**이다 (사용자가 "관리자 UI도 사용자 UI처럼" 요청). 관리자에서는 색을 상태에만 쓴다(빨강 = 문제 있음, 초록 = 처리됨)
- **애니메이션은 담백하게**: 화면 들어올 때 살짝, 카드 확대, 채점 순간 화면 테두리(초록·빨강+흔들림). 카드 밀기는 **가로로만**(기울기·흐림 없음). 처음 안내 알림 같은 군더더기는 넣지 않는다
- **AI 질문용 복사 버튼**: 평소 회색, **누를 때와 "복사됨 ✓" 동안만 파란색**(`--cpy-*` 토큰)
- 폰 화면이 기본: 375~400px에서 가로로 넘치지 않게, 입력칸은 16px 이상(폰 확대 방지)
- `prefers-reduced-motion`을 지킨다

## 4. 동작 규칙 (그동안 정한 것)
- **틀린 문제는 다시 풀 때까지 정답·해설·보기 색칠을 숨기고** "✕ 오답" 표시만 보여 준다. "내가 고른 답" 칸은 없다. 맞힌 문제는 펼쳐 둔다
- 방금 푼 문제는 필터(안 푼 문제·틀린 문제)에서 **바로 사라지지 않게** `keep`으로 잡아 두고, 다음으로 넘어갈 때 그 카드만 뺀다(`prune`, 전체를 다시 그리지 않음)
- **나중에 볼 문제**: 카드 오른쪽 위 ☆. 그 화면에서 뺀 문제는 나갈 때까지 남겨 둔다(`unsaved`)
- 채점 뒤에는 **그 카드만** 다시 그린다(`renderCard`). 보던 카드 위치가 밀리지 않게 스크롤을 보정한다
- **수식 과목은 보이는 카드만 수식을 그린다**(집중 모드: 지금·앞뒤 / 목록: 화면 근처 800px). 다시 그리기 전에 `clearMath`로 예전 수식을 지운다. 수식 설정·CSS는 `math.js`에서만 고친다(문장 속 수식은 `display:inline`, SVG에는 위쪽 여백만. 아래 여백·inline-block은 수식이 떠 보이게 한다)
- **저장**: 모든 기록은 먼저 localStorage(`mn:` 접두사), 동의한 기기만 서버 동기화(`pending` 대기열). 연결이 끊기면 15초마다 `/health`를 확인해 다시 닿으면 표시를 지우고 밀린 것을 보낸다
- **출처가 바뀌면 저장소가 비어 보인다**(Tunnel 주소 변경 등). 사용자는 기록 열쇠·이동 코드로 되찾는다. 이 흐름(첫 접속 안내의 "코드나 기록 열쇠로 가져오기", 마이페이지 "내 기록 열쇠")을 망가뜨리지 않는다
- 이벤트(`track`)는 동의한 기기만 보낸다. 새 상호작용을 만들면 관리자 통계에 쓸 수 있게 이벤트를 하나 더하는 것을 검토한다(DB 담당에 type과 payload를 알린다)

## 5. 확인하는 법
- 이 맥 크롬의 `127.0.0.1:4000` 사용자 웹은 **사용자 본인 기록과 같은 저장소**다. 화면을 보는 것은 괜찮지만, 풀이·담기 같은 시험은 하지 않는다.
- 시험은 **DB 복사본 + 4001번 서버**에서 한다. 4001은 출처가 달라 브라우저 저장소도 따로다.
  ```bash
  node -e 'const {DatabaseSync}=require("node:sqlite");new DatabaseSync("data/app.db",{readOnly:true}).exec("VACUUM INTO '"'"'<스크래치>/test.db'"'"'")'
  DB_PATH=<스크래치>/test.db PORT=4001 node server/server.js
  ```
  시험 기기는 콘솔에서 `localStorage.setItem('mn:device', JSON.stringify({id:'TEST…(16자 이상)', nickname:'', consent:true}))`로 만든다. 끝나면 `localStorage.clear()`, 서버 끄기, 복사본 지우기.
- 정적 파일은 수정하면 바로 반영된다(서버 재시작 필요 없음, 새로 고침만).
- 폰 너비 확인: 창 크기를 못 바꾸면 같은 출처의 375px iframe으로 `scrollWidth`를 잰다.
- 수식 과목(공학수학 `/course/4/...`)과 수식 없는 과목(경정시 `/course/5/...`) 둘 다 본다. 라이트·다크 둘 다 본다.

## 6. 앞으로 할 일 (사용자가 고르면)
1. **React로 옮기기**(7단계): 화면별 파일을 컴포넌트로, `store.js`는 상태 저장소로. 디자인 토큰·CSS는 그대로
2. 데이터 수집 안내 페이지, "내 기록 모두 지우기" 버튼(서버 API와 함께)
3. 공수2 핵심 개념·모의고사 화면 (예전 공수2 앱에 있던 것, `course.info.concepts`에 내용이 있음)
4. 관리자: 이벤트 기반 지표(나중에 볼 문제 많이 담긴 문제 등), 문제 품질 표의 폰 화면
5. 박준석 모드(예전 허브의 재미 기능)는 옮기지 않았다. 사용자가 원하면 설정 토글로
